ORGANIZER UPI QR CODE
=====================

The QR code that is live on the site is:

    upi-qr.png

It was installed from the image the organizer supplied. The registration page
finds it automatically, so nothing in the code needs to change.

To replace it, drop your new image in this folder using one of these names:

    upi-qr.png
    upi-qr.jpg
    upi-qr.jpeg
    upi-qr.webp

Then reload the registration page.

Important
---------
* The image is shown exactly as supplied. It is not cropped, recoloured or
  redrawn, so the QR keeps scanning correctly.
* Keep the image large and sharp (at least 600 x 600 pixels).
* If you delete the file without replacing it, the payment section shows a
  short organizer note instead of a QR code.
* Never place a sample or placeholder QR here. This folder is public.
